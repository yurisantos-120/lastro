# 8. Glossário

| Termo | Significado neste projeto |
|---|---|
| API | Interface HTTP usada pelo navegador para ler e salvar dados |
| Binding | Nome lógico que conecta o código a um recurso da plataforma, como `DB` |
| Build | Processo que valida e transforma o código para produção |
| Categoria | Agrupador configurável de informações operacionais |
| Cloudflare D1 | Banco relacional persistente compatível com SQLite |
| CRUD | Criar, ler, atualizar e excluir registros |
| Drizzle | Ferramenta de definição de esquema e geração de migrações |
| Eidos | Marca responsável pelo desenvolvimento do sistema |
| HMR | Atualização automática da página durante o desenvolvimento |
| Informação | Registro operacional vinculado a uma categoria |
| Migração | Arquivo SQL que altera a estrutura do banco de forma versionada |
| NOC | Centro de Operações de Rede |
| pnpm | Gerenciador de dependências e scripts Node.js usado pelo projeto |
| React | Biblioteca responsável pela interface interativa |
| Route Handler | Código de servidor que responde a uma rota HTTP |
| SQLite | Modelo de banco relacional usado pelo D1 |
| Tailwind CSS | Sistema de classes utilitárias usado na estilização |
| TypeScript | JavaScript com tipos, usado no cliente e no servidor |
| Vinext | Framework que oferece rotas e renderização no estilo Next.js sobre Vite |
| Vite | Ferramenta de desenvolvimento e build |
| Worker | Processo de servidor executado na infraestrutura Cloudflare |
