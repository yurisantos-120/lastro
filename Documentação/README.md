## Resumo para começar

No terminal integrado do VS Code:

```powershell
pnpm install
pnpm dev
```

Depois, acesse `http://localhost:3000`. Também é possível executar a tarefa **Lastro: iniciar desenvolvimento** pelo menu **Terminal > Run Task**.
